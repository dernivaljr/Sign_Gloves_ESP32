# Sign_Gloves_ESP32
Projeto TCC – Luva tradutora de Libras (ESP32 + PlatformIO)

## Build
- VS Code + PlatformIO
- Placa: ESP32 Dev Module (ou ESP32-C3, ajustar `platformio.ini`)
- Compilar: `PlatformIO: Build`
- Gravar: `PlatformIO: Upload`
- Monitor Serial: `PlatformIO: Monitor`

## Estrutura
- `src/` – código-fonte (`main.cpp`)
- `include/` – headers
- `lib/` – bibliotecas locais
- `test/` – testes (opcional)
- `platformio.ini` – ambientes/placas
